## November 13, 2026

### Version 2.0.0

This is a major release: a site that built with 1.9.1 can stop building or look different after upgrading. Read **Upgrading to 2.0.0** below before you upgrade.

- Added content validation. Every build checks all Markdoc content, lists each problem with its file and line, and stops on errors.
- Added the advanced image, with a caption and click to enlarge. See [Advanced Images](/writing-content/advanced-images).
- Added support for diagrams on landing pages. See [Landing Pages](/writing-content/landing-pages).
- A plain image no longer shows a caption or opens larger when clicked. See [Images](/writing-content/images).
- Variables in code blocks are now filled in. See [Variables](/configuration/variables).
- Updated Markdoc to 0.5.12 and other dependencies to their latest versions.

#### Upgrading to 2.0.0

- Fix the problems the build reports.
- Add `{% process=false %}` to code blocks that show Markdoc syntax as written, so their tags and variables aren't filled in.
- Use an advanced image where you want a caption or click to enlarge.
- Use the hero and sections only on landing pages.

## October 29, 2026

### Versions 1.9.0 and 1.9.1

- Added API Reference support. Mordoc now generates one documentation page for every operation in your OpenAPI specs, including parameters, request and response schemas, and examples. See [API Reference overview](/api-reference/overview).
- Added the `config/api.yaml` file for registering OpenAPI specs and choosing the route each one is served from. See [API Registry](/configuration/api-registry).
- Added enrichment files for patching descriptions and adding field notes to generated API pages without editing the spec. See [Enrich descriptions](/api-reference/enrich-descriptions).
- Added badges for fields in API pages, including the reserved `conditional` badge and free-text badges. See [Badges](/api-reference/badges).
- Added the `operation` key for sidenav entries to link generated API pages in your navigation. See [Link operations in navigation](/api-reference/link-operations-in-navigation).
- Added build warnings and errors for common problems in API specs and enrichment files, with an optional strict mode that fails the build on any warning. See [Warnings and errors](/api-reference/warnings-and-errors).
- API pages now show webhooks defined in your OpenAPI specs.
- Parameters in API pages are now individually searchable, so search results open directly at the matching parameter.
- Improved the build and dev server startup output in the terminal.
- Added a friendly error page, translated into all supported interface languages, for unexpected errors while browsing the site.
- Updated dependencies to their latest versions.
- Bug fixes and minor UI improvements.

## August 31, 2026

### Version 1.8.1

- Fixed the stale build version of Mordoc that was missed in the previous published version and added safeguard to automatically build during publish.

### Version 1.8.0

- Added the Clip component for short, self-hosted, click-to-play demo videos. See [Clips](/writing-content/clip).
- Added the Video Embed component for embedding videos already hosted on YouTube, Vimeo, or Loom. See [Video Embeds](/writing-content/video-embed).
- Added Accordion and Accordions components for collapsible content sections, standalone or grouped. See [Accordions](/writing-content/accordions).
- Added the Columns component for laying out content side by side. See [Columns](/writing-content/columns).
- Added footer configuration support, including translated footer lines. See [Footer](/configuration/footer).
- Fixed site-wide interface text (search, "On this page", menu labels, and similar texts you didn't author) to translate automatically into Spanish, French, German, Portuguese, Japanese, Chinese (Simplified), Korean, Italian, Dutch, Russian, Arabic, and Hindi.
- Added a default view height limit to code blocks.

## August 22, 2026

### Version 1.7.0

- Added support for advanced customization of Mordoc documentation website.
- Implemented default font loading directly from the Mordoc project instead of doing this via Google APIs.
- Added support for users to setup their own custom fonts.
- Increased default article max width to use more of whitespace.
- Updates to Hero and Section components syntax to seperate color configuration in css files. **Minor breaking change for landing pages**. See [Landing Pages](/writing-content/landing-pages) for updated syntax.
- Fixed the side navigation scrolling issue for Chrome browser in mobile phones.

## July 30, 2026

### Version 1.6.6

- Complete refactor of Mordoc architecture.
- Added feature diagram as a code starting with sequence diagrams.
